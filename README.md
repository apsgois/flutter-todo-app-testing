# Flutter Task Manager Testing

A cross-platform **task management application built with Flutter**, developed as an academic project focused on software testing and application behavior validation.

The project provides a practical environment for exploring Flutter development, automated testing, and software quality concepts.

## 📱 Project Overview

The application implements a simple task management system that allows users to work with a list of tasks while providing automated tests to validate application behavior.

The project was developed to combine practical **Flutter development** with concepts related to **software testing and quality assurance**.

## ✨ Features

* Task list management
* Cross-platform Flutter application
* Automated tests
* Application behavior validation
* Multi-platform support

## 🧪 Testing

Automated tests are included in the `test/` directory.

To execute the test suite:

```bash
flutter test
```

The tests were developed to validate application behavior and provide practical experience with automated testing in Flutter.

## 🚀 Getting Started

Make sure Flutter is installed and properly configured.

Install the project dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

Run the automated tests:

```bash
flutter test
```
